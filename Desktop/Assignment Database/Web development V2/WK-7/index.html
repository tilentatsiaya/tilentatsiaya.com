Implementation Details

Part 1: CSS3 Transitions and Animations

The pendulum uses CSS keyframe animations for the swinging motion. The bob has a hover effect with CSS transitions for smooth scaling. The gradient backgrounds and shadows create a visually appealing design.

Key CSS features used:

  • @keyframes swing for the pendulum motion
  • transform-origin to set the rotation point at the top
  • transition for smooth hover effects
  • CSS gradients for realistic materials

Part 2: JavaScript Functions

JavaScript functions control the animation with parameters for speed and angle. The functions demonstrate proper scope usage and return values when needed.

Key JavaScript features:

  • Function parameters for customization
  • Local vs global scope management
  • DOM manipulation to update animation properties
  • Event listeners for user interaction

Part 3: Combining CSS Animations with JavaScript

JavaScript dynamically controls the CSS animation by updating custom properties and toggling classes. The user can start, stop, and adjust the pendulum's behavior.

Integration techniques:

  • JavaScript control of CSS animation properties
  • Dynamic style updates based on user input
  • Class toggling to enable/disable animations
